Paddle2IP

Remote CW paddle over IP · M5Stack Dial (ESP32-S3)

Firmware 20261019.2 · built 2026-10-19 19:32 UTC from fd6ab1c
This browser cannot flash: use Chrome or Edge on a desktop computer. Web Serial needs HTTPS or localhost.
  1. Connect the Dial with a USB-C data cable.
  2. Click Flash firmware and pick the port (USB JTAG/serial debug unit).
  3. When asked, do not erase the device if you want to keep the settings (WiFi, server, shared key). Erase only for a clean start.
  4. After flashing, press the reset button or reconnect the power.

No port shows up: try another cable (many USB-C cables are charge-only) and close any serial monitor that holds the port.

First setup, operation and the protocol are described in the README. The server side runs on the Open Interface III.
